<h1 align="center">

  Brain Boosters
</h1>

<p align="center">
  <strong>Brain Boosters</strong> は、批判的思考力を高め、より良い意思決定をサポートするためのランダムなアドバイスを提供するWebアプリケーションです。
</p>

<img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
|------|------|
| 🎯 ランダムアドバイス生成 | 役立つアドバイスをすぐに取得できます |
| ⚡ ワンクリック操作 | ボタンをクリックするだけで新しいアドバイスを表示 |
| 🧠 思考力向上 | 批判的思考を育てるための有益な提案を提供 |
| 🎨 シンプルなUI | ミニマルで使いやすいデザイン |
| 🌐 Webベース | インストール不要でブラウザから利用可能 |
| 📱 レスポンシブデザイン | PC・スマートフォン・タブレットで快適に利用可能 |

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/BrainBoosters.git
```

### 2️⃣ プロジェクトフォルダへ移動する

```bash
cd BrainBoosters
```

### 3️⃣ ブラウザで開く

`index.html` を任意のWebブラウザで開くだけで利用できます。
