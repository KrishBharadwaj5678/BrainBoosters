# 🧠 Brain Boosters

**BrainBoosters** is a simple web app that delivers random advice to inspire better thinking and smarter decisions.
Get quick wisdom and daily motivation with just one click.

![BrainBoostersDemo](https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/BrainBoostersDemo.png)

## ✨ Features

| Feature                    | Description                                           |
| -------------------------- | ----------------------------------------------------- |
| 🎯 Random Advice Generator | Get useful and inspiring advice instantly             |
| ⚡ One Click Interaction    | Simply click to receive a new piece of advice         |
| 🧠 Mind Enrichment         | Helpful suggestions to improve thinking               |
| 🎨 Clean UI                | Minimal and user-friendly design                      |
| 🌐 Web-Based               | Accessible from any browser without installation      |
| 📱 Responsive Design       | Works smoothly on desktop and mobile devices          |

---

## 🛠️ Tech Stack

| Technology        | Purpose                                |
| ----------------- | -------------------------------------- |
| 🌐 **HTML5**      | Structure of the web application       |
| 🎨 **CSS3**       | Styling and responsive design          |
| ⚡ **JavaScript**  | Adds interactivity and API integration |
| 🔗 **Advice API** | Fetches random advice dynamically      |

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/BrainBoosters.git
```

### 2️⃣ Navigate to the Project

```bash
cd BrainBoosters
```

### 3️⃣ Open in Browser

Simply open `index.html` in your browser.
