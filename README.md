<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/favicon/favicon.svg" width="35"/> Brain Boosters</h1>

<p align="center">
  Brain Boosters is a web application that provides random pieces of advice designed to encourage critical thinking and better decision-making. 
</p>

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                    | Description                                           |
| -------------------------- | ----------------------------------------------------- |
| 🎯 Random Advice Generator | Get useful and inspiring advice instantly             |
| ⚡ One Click Interaction    | Simply click to receive a new piece of advice         |
| 🧠 Mind Enrichment         | Helpful suggestions to improve thinking               |
| 🎨 Clean UI                | Minimal and user-friendly design                      |
