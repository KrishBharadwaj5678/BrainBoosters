<h1 align="center">

  Brain Boosters
</h1>

<p align="center">
  <strong>Brain Boosters</strong> é uma aplicação web que fornece conselhos aleatórios para incentivar o pensamento crítico e ajudar na tomada de melhores decisões.
</p>

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------- | --------- |
| 🎯 Gerador de Conselhos Aleatórios | Receba conselhos úteis e inspiradores instantaneamente |
| ⚡ Interação com Um Clique | Basta clicar para receber um novo conselho |
| 🧠 Desenvolvimento do Pensamento | Sugestões úteis para melhorar o pensamento crítico |
| 🎨 Interface Limpa | Design minimalista e fácil de usar |
| 🌐 Baseado na Web | Acessível em qualquer navegador sem necessidade de instalação |
| 📱 Design Responsivo | Funciona perfeitamente em computadores, tablets e dispositivos móveis |
