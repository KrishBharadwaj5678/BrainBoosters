<p align="center">
  <strong>Brain Boosters</strong> это веб-приложение, которое предоставляет случайные полезные советы, направленные на развитие критического мышления и принятие более взвешенных решений.

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ------------ | -------- |
| 🎯 Генератор случайных советов | Получайте полезные и вдохновляющие советы мгновенно |
| ⚡ Взаимодействие в один клик | Просто нажмите кнопку, чтобы получить новый совет |
| 🧠 Развитие мышления | Полезные рекомендации для улучшения критического мышления |
| 🎨 Чистый интерфейс | Минималистичный и удобный дизайн |
| 🌐 Веб-приложение | Доступно из любого браузера без установки |
| 📱 Адаптивный дизайн | Корректно работает как на компьютерах, так и на мобильных устройствах |

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/BrainBoosters.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd BrainBoosters
```

### 3️⃣ Откройте приложение в браузере

Просто откройте файл `index.html` в любом современном веб-браузере.
